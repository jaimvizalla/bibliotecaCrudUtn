# 📚 Biblioteca - CRUD

Este proyecto busca simular el **CRUD de una biblioteca** para demostrar el entendimiento de los conocimientos brindados por el **curso Backend de la UTN**.

Es un código simple, pensado como base sobre la cual iremos incorporando más herramientas y profundizando los temas del curso a medida que avancemos.

## ⚙️ Funcionalidades

- ➕ Crear un libro
- 📖 Leer libros
- ✏️ Actualizar un libro
- 🗑️ Eliminar un libro
